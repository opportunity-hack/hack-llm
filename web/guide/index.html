One AI gateway, every coding tool

Point Claude Code, Cursor, Cline, Continue, or any OpenAI/Anthropic SDK at the OHack endpoint with the keys on your team card. Setup takes about two minutes.

Endpoint https://ai.ohack.dev/v1
Key 1 $15 budget · models ohack ohack-free
Key 2 $20 budget · model ohack-frontier
Models ohack fast + cheap default, auto-falls-back if a provider is down · ohack-frontier the big gun — save it for hard problems · ohack-free rate-limited but costs nothing

That's $35 per team total. When a budget runs out, requests return a clear budget_exceeded error — find an organizer. Examples below use Key 1; to use ohack-frontier, swap in Key 2 and set the model name to ohack-frontier.

Command lineClaude Code

Export these before launching claude (note: base URL has no /v1 — Claude Code adds it):

export ANTHROPIC_BASE_URL="https://ai.ohack.dev"
export ANTHROPIC_AUTH_TOKEN="sk-YOUR-KEY-1"
export ANTHROPIC_MODEL="ohack"
export ANTHROPIC_SMALL_FAST_MODEL="ohack"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="ohack"
claude

Or make it stick in ~/.claude/settings.json:

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://ai.ohack.dev",
    "ANTHROPIC_AUTH_TOKEN": "sk-YOUR-KEY-1",
    "ANTHROPIC_MODEL": "ohack",
    "ANTHROPIC_SMALL_FAST_MODEL": "ohack",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "ohack"
  }
}

Frontier session instead: open a separate terminal and set all five vars for Key 2 — ANTHROPIC_AUTH_TOKEN to Key 2, and all three model vars to ohack-frontier (Key 2 only allows that model).

EditorCursor

  1. Settings → Models → API Keys → OpenAI API Key: paste Key 1.
  2. Enable Override OpenAI Base URL and set it to https://ai.ohack.dev/v1.
  3. Add a custom model named ohack. (For ohack-frontier, switch the API key to Key 2 and add that model name.)

VS CodeCline

  1. Cline settings → API Provider → OpenAI Compatible.
  2. Base URL: https://ai.ohack.dev/v1
  3. API Key: Key 1
  4. Model ID: ohack

VS CodeContinue

Add to ~/.continue/config.yaml:

models:
  - name: ohack
    provider: openai
    model: ohack
    apiBase: https://ai.ohack.dev/v1
    apiKey: sk-YOUR-KEY-1

SDKPython (OpenAI SDK)

from openai import OpenAI

client = OpenAI(base_url="https://ai.ohack.dev/v1", api_key="sk-YOUR-KEY-1")
r = client.chat.completions.create(
    model="ohack",
    messages=[{"role": "user", "content": "Hello from OHack!"}],
)
print(r.choices[0].message.content)

SDKNode (OpenAI SDK)

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://ai.ohack.dev/v1",
  apiKey: "sk-YOUR-KEY-1",
});
const r = await client.chat.completions.create({
  model: "ohack",
  messages: [{ role: "user", content: "Hello from OHack!" }],
});
console.log(r.choices[0].message.content);

Command linecurl (smoke test)

One line on purpose — multi-line commands with \ break when pasted into PowerShell or some terminals. Windows: use curl.exe and escape the inner quotes as \".

curl -s https://ai.ohack.dev/v1/chat/completions -H "Authorization: Bearer sk-YOUR-KEY-1" -H "Content-Type: application/json" -d '{"model":"ohack","messages":[{"role":"user","content":"say ok"}]}'
Where your prompts go The default ohack model uses Meta's Contributor tier. Your prompts and generated code may be used by Meta to train its models. All OHack projects are open source, so this matches how your code will be published anyway. If your team objects, use ohack-free.

Troubleshooting

SymptomMeaningFix
401 Bad or missing key Re-copy the key from your card; check for stray spaces
429 + budget_exceeded That key's budget is spent Find an organizer
"model not allowed" Wrong key for the model ohack-frontier needs Key 2; everything else needs Key 1
Slow responses Default lane is saturated Switch to ohack-free, or take a walk — it's a hackathon
Tool insists on a claude-* model Some tools filter model pickers Type the model name ohack manually (env var or custom model entry)

Keys are shared by your whole team. Don't commit them, don't post them, don't paste them into public demos — leaked keys get revoked and you'll need a spare from an organizer.
